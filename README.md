# Lesley Magaramombe Portfolio

A responsive, single-page portfolio built with plain HTML, CSS, and JavaScript. Open `index.html` directly in a browser or publish the folder with GitHub Pages.

The portfolio includes custom CSS project illustrations, category filters, a mobile navigation menu, an about section, toolkit, and GitHub links. The project descriptions are based on the repository summaries shared for this draft. Replace any sample dashboard values with real project screenshots or verified data before publication.
